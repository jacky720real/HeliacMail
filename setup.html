📖 极简教程：5 分钟跑起 Vikunja + 手机 App
1) 最简单：点上方【⚡ 一键部署本地 Vikunja】即可在本机 vikunja_local\ 用官方 Windows exe 自动下载、部署、建号并接入（免 Docker）。
也可以自己在任意一台能跑 Docker 的服务器/VPS 上运行：docker run -d -p 3456:80 -v vikunja:/app/vikunja kolaente/vikunja（此时手动填服务器地址）。
2) 一键部署会自动创建永久 API Token（tk_ 开头）并写入上方设置，无需手动复制。只有你在别的机器/云服务器上自建时才需手动：浏览器打开 http://服务器:3456 登录 → 右上角头像 → 设置(Settings) → API Tokens → 新建：填名称、勾选 API 范围（可全选）、设过期时间（留空=永不过期）→ 创建后复制 tk_ 开头的令牌填到上面。
3) 手机安装 Vikunja App（Android：Play/F-Droid；iOS：App Store）→ 添加自建服务器：
  · 手机与电脑同 Wi-Fi：填电脑的局域网 IP:3456（见上方 vkNet 检测结果）；
  · 手机与电脑异地：优先推荐Tailscale（免费、稳定、点对点），或选 Cloudflare Tunnel 后点下方「☁️ 一键安装并启动隧道」（免装到手机，自动给 https 公网地址）；
  · 账号密码：一键部署产生的账号密码在 vikunja_local\admin.txt。
4) 回到本工具点「🧪 测试连接」→ 保存后新邮件待办即自动出现在手机 App 里；在 App 里勾完成会自动同步回本仪表板。
说明：Todoist / Microsoft To Do 接入需要额外的 OAuth 应用授权，已在规划中，届时只需在“后端”下拉里切换即可。

🧭 告诉 AI：什么对你更重要

AI 分析每封邮件时都会参考这里的说明与权重：权重越高，越可能被当作重要邮件（影响分类 / 紧急度 / 摘要详略 / 是否生成待办）。仅在你调用 AI 时随提示词发出，不影响关键词兜底模式。
技巧：权重调高会鼓励 AI 对这类邮件“宁多勿漏”地判断重要性与待办；调低则会“宁可空数组”。说明文字请写清你的处境、优先级与时间要求。
